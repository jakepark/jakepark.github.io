This site

Type
Personal project
Year
2026
Source
GitHub

Rebuilt my 2015 portfolio by hand and made the P-51 fast enough to keep.

Starting point
A template site scoring 51 on mobile PageSpeed. The largest element took 29.6 seconds to appear because the browser was busy parsing a 3.1 MB 3D model.
Constraints
Static hosting on GitHub Pages, which won’t compress binary files. Keep the 3D model, since I made it.
Build
A Python script bakes the model into a compact line list with delta-encoded indices. A small WebGL renderer draws it directly instead of loading three.js, and only redraws when you turn it.
Result
The model file went from 3.1 MB to 300 KB, and the 3D code from 430 KB to about 8 KB.
  1. p51.obj3.1 MB text
  2. build_wireframe.pymerge, dedupe edges
  3. p51.wire300 KB binary
  4. WebGLgl.LINES, on demand
